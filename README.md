# Nauka Git i GitHub

Interaktywny kurs Gita i GitHuba po polsku: animowane diagramy commitów, terminal, quizy i piaskownica z drugą osobą do ćwiczenia pull requestów.

Cała aplikacja to jeden plik `index.html` (HTML, CSS i JavaScript, bez frameworków i bez serwera). Polecenia `git` i `gh` działają na symulatorze w przeglądarce, a postęp zapisuje się w `localStorage`.

## Uruchomienie

Otwórz `index.html` w przeglądarce albo włącz GitHub Pages dla tego repozytorium.
